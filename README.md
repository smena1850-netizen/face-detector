# 👁️ Face & Eye Detector — Computer Vision Project

مشروع Python لكشف الوجوه والعيون والابتسامة في الصور أو الكاميرا المباشرة باستخدام **OpenCV Haar Cascades**.

---

## 📦 التثبيت

```bash
pip install -r requirements.txt
```

---

## 🚀 الاستخدام

### 1. على صورة من عندك
```bash
python detect.py --image صورتك.jpg
```

### 2. مع حفظ النتيجة
```bash
python detect.py --image صورتك.jpg --output output/result.jpg
```

### 3. كاميرا في الوقت الفعلي
```bash
python detect.py --camera
```
> اضغط **Q** أو **ESC** للخروج

### 4. تجربة سريعة بدون صورة
```bash
python demo.py
```

## 🧠 إزاي بيشتغل؟

المشروع بيستخدم **Haar Cascade Classifiers** — خوارزمية كلاسيكية في Computer Vision:

1. بتحوّل الصورة لـ **Grayscale** عشان أسهل في التحليل
2. بتطبّق الـ cascade على الصورة كلها للكشف عن **الوجوه**
3. جوّا كل وجه، بتطبّق cascade تاني للكشف عن **العيون**
4. في النصف السفلي من الوجه، بتدور على **الابتسامة**
5. بترسم مستطيلات على النتيجة وبتطبع الإحصائيات

## ⚠️ ملاحظات

- الصور الواضحة وذات الإضاءة الجيدة بتدي نتيجة أحسن
- الكشف بيتم على الوجوه **من الأمام** فقط (frontal face)
- لو الكشف مش دقيق، جرب صور بإضاءة أفضل أو وجه أوضح
